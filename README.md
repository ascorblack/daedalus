# Daedalus

Персональный Telegram-агент на ядре `protocore` (community edition), живущий в
Docker-контейнере на Ubuntu без ограничений внутри, с возможностью
дорабатывать самого себя (код бота, Mini App, локальный клон ядра) и
перезапускаться для применения изменений.

Назван в честь Дедала — мастера, который построил себе крылья.

Состояние: **концепт / проектирование** (2026-09-05). Кода ещё нет.

- `docs/DESIGN.md` — архитектура и принятые решения (текст + topics + Mini App).
- `docs/RESEARCH.md` — обзор похожих проектов и что из них берём.
- `docs/DECISIONS.md` — решения владельца по открытым вопросам.
- `docs/GITHUB-ACCESS.md` — как выдать агенту доступ к его репозиториям.
- `docs/PLAN.md` — план реализации.
