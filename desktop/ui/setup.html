How it runs on this machine

Both run the same agent. The difference is what is around it, and it is worth a moment: it is the one answer here that is awkward to change later.

A model to think with

One key is enough. Keys are written to daedalus-secrets/keyproxy.env, outside every folder the agent can read, and reach the provider through the key proxy — the agent process never holds one.

A field left empty keeps whatever is already in force — nothing here is ever blanked by accident. Tick remove to empty one on purpose.

No key at all is fine if you are signed in to the ChatGPT (Codex), Claude Code or SuperGrok CLI on this machine: those logins are mounted into the key proxy and become providers of their own.

Telegram optional

Telegram is optional; without it you use the app in the browser. With it, every forum topic becomes a session you can write to from your phone.

Spending

The cap is enforced twice: by the supervisor, which the agent cannot edit, and by the key proxy, which stops paying once the day's budget is spent.

The first start downloads what the mode above needs — the images for Docker, the portable runtime for native — and then opens the app.
