# Решения владельца (2026-09-06)

Ответы на вопросы первого отчёта. Это источник истины для дизайна; `DESIGN.md` им следует.

| # | Тема | Решение |
|---|---|---|
| 1 | Режим | Гибрид: топики-сессии + Mini App. |
| 2 | Пользователи | **Ровно один.** Бот — личный агент, который любой поднимает на своём сервере со своими моделями. Никакой мультитенантности. |
| 3 | Хостинг | Контейнер на сервере владельца. Агент **может менять Dockerfile и запускать пересборку** (чтобы установленные зависимости не пропадали). |
| 4 | Self-change | Настраиваемо. По умолчанию: сообщение с описанием изменений и кнопками **Одобрить / Отказать / Отказать с причиной** (последняя запрашивает текст причины, который уходит агенту). |
| 5 | Файлы > 20 МБ | Нужны — локальный Bot API server закладывается сразу. |
| 6 | Расходы | Показывать максимально подробно всё, что отдаёт провайдер (начинаем с DeepSeek). В Mini App — обязательно. Плюс **монитор баланса**: раз в минуту опрашивать остаток на счёте DeepSeek, при пересечении настраиваемых порогов (их может быть несколько) — уведомление в General-топик. |
| 7 | Git / self-develop | Два приватных репо под `ascorblack`: **`daedalus`** (бот) и **`protocore-exp`** (копия protocore-community). Агент имеет PAT только на эти два, внутри контейнера стоит `gh`. Механизм self-develop = **Pull Request**: агент открывает PR → одобрение (ручное или авто) → merge в `main` → агент триггерит пересборку, которая тянет новый код. Секреты и файлы, которые должны пережить пересборку, — через volume, локально, не в git. |
| 8 | Модель | `DeepSeek-V4-Flash-0731` по умолчанию. Thinking настраивается: on/off + `reasoning_effort`; по умолчанию **on, medium**. |
| 9 | Язык | System prompt, скиллы, внутренние промпты — английский (экономия токенов). Финальный ответ — **на языке запроса**. |
| 10 | Ввод | Голоса пока нет. **Полная поддержка файлов сразу**: текст, текст+файл (caption), файлы, картинки — в любой момент работы агента, включая старт. Файл, присланный в топик, кладётся в workspace этой сессии, агенту передаются пути. Follow-up сообщения во время работы — обязательно. |
| 11 | Mini App | Стиль **grok.com / Grok Bot** (x.ai/news/designing-grok-bot, реконструкция b-nnett/grok-bot-0.18-reconstructed). Стек не принципиален. |
| 12 | Планировщик | Встраиваем сразу. Агент сам создаёт себе задачи, прикрепляя файлы из своего текущего workspace. Повторяющаяся задача имеет **свой постоянный workspace** и получает контекст (summary) предыдущего срабатывания. |

Дополнительно:

- Используем **только** ядро protocore-community (через копию `protocore-exp`). Никаких
  зависимостей от других, закрытых репозиториев.
- Репозитории пока private; перед открытием — аудит истории и содержимого на утечки.
